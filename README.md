# Network & Cybersecurity Academic Portfolio

This repository contains a collection of academic projects and laboratory exercises completed during my studies at the **Department of Informatics, Athens University of Economics and Business (AUEB)**.

## 📁 Included Projects

### 1. SolarWinds Supply Chain Attack Analysis
*   **File:** `SOLARWINDS SUPPLY CHAIN ATTACK.pdf`
*   **Description:** A comprehensive analysis of the 2020 SolarWinds attack using the **MITRE ATT&CK** framework and **Cyber Kill Chain**. Examines APT29 tactics, the SUNBURST backdoor, and proposes defensive strategies such as **Zero Trust Architecture** and **SBOM**.

### 2. ARP Spoofing (Man-in-the-Middle) Lab
*   **File:** `ARP SPOOFING.pdf`
*   **Description:** Practical execution of an ARP cache poisoning attack in a virtualized environment (Kali Linux, Ubuntu). Includes traffic interception using **Wireshark** and **urlsnarf**, along with proposed mitigations.

### 3. Network Enumeration with Nmap
*   **File:** `NMAPLAB.pdf`
*   **Description:** Network scanning, port discovery, service enumeration, and OS fingerprinting using **Nmap** in a lab environment.

## 🛠️ Tools & Technologies Used
*   **Security Tools:** Kali Linux, Wireshark, Nmap, urlsnarf
*   **Frameworks:** MITRE ATT&CK, Cyber Kill Chain
*   **Virtualization:** VirtualBox, Ubuntu, Kali Linux
*   **Concepts:** Network Security, Threat Analysis, Incident Response, Zero Trust
